Movie Webpage Project

Context

To wrap up our HTML unit we did a project using our knowledge of HTML and CSS to make a fake movie website. Me and my partner thought it would be best to make our own comedy/ action movie, The space apocalypse.

Content

We have the basic idea of what our movie was going to be about and how to build the website, but we needed to divide up the work because it was too much for one person to do. So we use the planner and sign each other work is equally could. I used basic HTML and CSS to add some elements to the website like...

  • class/id/element
  • color scheme
  • margin
  • Import Google Fonts

Reflection

I often times found myself confused when I try to code something specific. For example, adding a two-tone gradient, which is something we haven't gone over, even in Free Code Camp. So I turn to the internet and found W3 Schools to be extremely helpful, giving detailed explanations as to how code correctly. And even examples from time to time. One other issue I had with the project overall that I wished I had addrsed sooner was not with any of the aspects of the coding, but with the partnership. I feel like more open and clear communication would have made things a little easier, as things did get a little jittery at the end. Who's doing what? He's absent, so do I just do his part or wait until he does it? How do I contact him? Better communication would have solved these problems without much trouble.
